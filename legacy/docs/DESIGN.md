# DESIGN (binding for app/assets/style.css, app/layout.py, app/charts.py, notebook visuals)

Skills applied: impeccable (Operate + Read modes, craft floor), design-taste-frontend (anti-slop), design-motion-principles (Emil lens: restraint), ui-ux-pro-max (priority list: accessibility, touch, layout, type/color, motion, forms), humanizer (copy). 21st.dev not used (React catalog; this stack is Dash).

## Read of the brief
Civic data story for graders and planners, light editorial tone, dials VARIANCE 4 / MOTION 3 / DENSITY 6. One family, one accent, one radius scale, one theme (system light/dark).

## Tokens (CSS variables on :root; dark under @media (prefers-color-scheme: dark))
Light: --bg #F3F5F4, --surface #FFFFFF, --surface-2 #E9EEED (filter rail), --line #D3DBD9, --text #14211F, --text-muted #4A5957, --accent #0E5A64, --accent-ink #FFFFFF, --focus #0E5A64 (2px ring + 2px offset), --warn #9A4B00, --danger #A12A2A.
Dark: --bg #0F1617, --surface #172021, --surface-2 #1D2829, --line #2C3A3B, --text #E6EDEC, --text-muted #A3B3B1, --accent #6CC4CB, --accent-ink #0A1415.
Chart categorical (Okabe-Ito, boroughs): Bronx #0072B2, Brooklyn #E69F00, Manhattan #009E73, Queens #CC79A7, Staten Island #56B4E9. Exposure: post #D55E00, pre #7A8B89, baseline #14211F. Sequential: single-hue teal ramp. Diverging: #0072B2 to #F3F5F4 to #D55E00. Never use the UI accent as a chart category. No pure #000/#FFF text. All text pairs >= 4.5:1, large >= 3:1.
Shape: one radius 8px for cards, inputs, buttons, chips; no pills. Shadows: none by default; menus 0 8px 24px rgb(20 33 31 / .12).
Type: "Geist" (Google Fonts via Dash external_stylesheets, fallback system-ui, -apple-system, Segoe UI, sans-serif) for everything; "Geist Mono" only for numbers in tables/KPIs with font-variant-numeric: tabular-nums. Fixed rem scale ratio 1.2: 0.8125, 0.9375, 1, 1.125, 1.35, 1.6, 2. Body 16px/1.55, prose max 68ch. Headings sentence case, tracking -0.01em, text-wrap: balance. No serif. No Inter. No gradient text.
Layout: header 56px single line (title left, three tabs right). Explore = sticky filter rail 300px (surface-2) + content (max 1400px). Charts in a 12-col grid with varied spans (wide: RQ3, RQ7; half: others), never six same cards; separate with spacing and hairlines, not nested cards. Mobile < 768px: rail collapses into an accordion above content, charts 1 column, targets >= 44px.
Components (all with default, hover, focus-visible, active scale .98, disabled, loading, error): primary button "Generate report" (accent fill, 44px high, one line), secondary "Apply search", dropdowns (dcc.Dropdown themed), range slider, search input with visible label above (no placeholder-as-label), chips for understood search tokens (8px radius, surface-2). Skeleton blocks (CSS shimmer 1.2s, off under reduced motion) while a report builds, not center spinners. Empty state teaches: names the filter that emptied it and a "Reset filters" button. Error state inline.
Chart style: transparent background, title states finding scope in plain words, axis titles with units, direct labels where possible, gridlines --line 1px, hover template always shows n and unit, legend horizontal under title, font Geist 12-13px, same margins everywhere, annotation for n and caveat in muted text, no chart junk, no 3D, no pie. Alt text via aria-label on each figure container (dcc.Graph wrapper div role="img" aria-label="...").
Motion (Emil lens, frequency gate): filter changes and dropdowns instant (no animation). Report refresh: charts cross-fade 160ms ease-out (cubic-bezier(.16,1,.3,1)); tab switch fade 180ms; button press scale .98 in 100ms. No page-load choreography, no parallax, no marquees, no looping animation. Only opacity/transform. @media (prefers-reduced-motion: reduce) disables all.
Browser surfaces themed: ::selection uses accent at 25%, caret-color accent, thin scrollbar (scrollbar-color line/surface), :focus-visible ring, tabular numerals, color-scheme: light dark.
Forbidden: emojis; icon glyph characters as icons; eyebrow labels above headings; section numbers; decorative dots; colored side-borders on cards; hard offset shadows; glassmorphism; hero metric template with identical big-number cards (use one plain stat row separated by hairlines, mono tabular numbers, labels beneath); modals; scroll cues; version labels; fake screenshots.

## Copy rules (humanizer)
Zero em dashes and zero en dashes in any user-visible string, docs prose, docstrings, and chart text; use commas, periods, colons, parentheses or a hyphen. Sentence case. Concrete verbs. Banned words: pivotal, crucial, delve, landscape, tapestry, testament, showcase, underscore, robust (figurative), seamless, leverage, unlock, journey, "not just X but Y", rhetorical one-line closers, triads for rhythm, "Let's dive in", chatbot phrases. Numbers always come from computed results; wording hedged ("is associated with", "no clear difference") and every finding says what the data cannot show. Straight quotes. No bold for decoration; bold only for control labels and table headers. Button labels name the action ("Generate report", "Apply search", "Reset filters").
